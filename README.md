# Archivo 404 — Casos sin resolver

Sitio del curso de Desarrollo Web (Coderhouse). Reúne fichas, expedientes y teorías de casos históricos que siguen sin una respuesta cerrada.

## Sitio desplegado

Enlace a GitHub Pages: https://TU-USUARIO.github.io/archivo-404/

Reemplazá `TU-USUARIO` por tu usuario de GitHub después de activar GitHub Pages y volvé a subir el README.

## Páginas

- Inicio: `index.html`
- Casos: `pages/casos.html`
- Expedientes: `pages/expedientes.html`
- Teorías: `pages/teorias.html`
- Contacto: `pages/contacto.html`

El inicio, Casos y Expedientes están adaptados a mobile y desktop. Teorías y Contacto comparten la misma base de estilos.

## Tecnologías

- HTML5
- CSS propio (mobile first, Grid y Flexbox) sobre la paleta del proyecto
- Bootstrap 5.3 (navbar, carrusel y acordeón), cargado por CDN
